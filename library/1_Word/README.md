# Lazy Dog Capital — Word Library

Editable `.docx` for every document in the loan workflow, organized by stage. The Capital Partner Pitch is also here as `.pptx`.

Every document appears **once**. No duplicates across folders — edit a file and you've edited the only copy.

A matching PDF library holds send-ready versions of all of these, plus six fillable forms that are PDF-only.

## Before any of this goes live

**Texas real estate attorney** — the 10C workout packet and a Chapter 53 notice-forwarding covenant for the Deed of Trust.

**Securities attorney** — the Capital Partner Agreement and Collateral Assignment. They must be told the structure is **per deal, per partner**, offered to multiple partners who each review and decide.
